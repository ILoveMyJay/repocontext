# Contributing to RepoContext

Thank you for your interest in contributing to **RepoContext**!

## Development Setup

1. Fork and clone the repository:
   ```bash
   git clone https://github.com/ILoveMyJay/repocontext.git
   cd repocontext
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run tests in watch mode:
   ```bash
   npm run test:watch
   ```

4. Build the project:
   ```bash
   npm run build
   ```

## Pull Request Guidelines

1. Ensure all tests pass: `npm test`
2. Follow existing code style and TypeScript conventions.
3. Add unit tests for new features or bug fixes.
